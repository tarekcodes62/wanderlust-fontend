# 🌍 Wanderlust - Travel Booking Platform

A modern, responsive travel booking web application built with Next.js, React,
and TypeScript. Explore destinations, manage bookings, and enjoy a seamless
travel planning experience.

## ✨ Features

- Responsive design for desktop, tablet, and mobile.
- User authentication with Better Auth.
- Explore and discover travel destinations.
- Create and manage travel bookings.
- Personalized booking management.
- Modern UI with reusable components.
- Dynamic routing with Next.js App Router.
- Secure API communication with the backend.

## 🛠️ Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Lucide React
- Better Auth
- MongoDB

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/tarekcodes62/wanderlust-client.git
```

### 2. Navigate to the project

```bash
cd wanderlust-client
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env.local` file in the project root.

```env
BETTER_AUTH_SECRET=your_secret_key
BETTER_AUTH_URL=http://localhost:3000
NEXT_PUBLIC_API_URL=http://localhost:5000
```

Add other environment variables required by your application. Keep secrets
private and never commit them to GitHub.

### 5. Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🏗️ Production Build

```bash
npm run build
npm run start
```

## 🌐 Deployment

This project can be deployed on [Vercel](https://vercel.com/).

1. Push your code to GitHub.
2. Import the repository into Vercel.
3. Configure the required environment variables.
4. Deploy the application.

Ensure your backend API is deployed and its URL is correctly configured.
